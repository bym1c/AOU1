# شاشة مؤتمر المبتكرين والمبدعين العرب
# Conference Live Screen

شاشة عرض تعمل تلقائياً مع الوقت الفعلي (توقيت مسقط UTC+4)، بدون إنترنت وبدون أي مكتبات خارجية.

## التشغيل
- افتح `index.html` في المتصفح واضغط **F11** لملء الشاشة.
- أو انشرها على GitHub Pages: Settings ← Pages ← Branch `main` / root.

## دورة العرض
الحدث الحالي دايماً على الشاشة، وكل 10 دقايق يطلع شي واحد بالتناوب (في آخر دقيقة من الـ10 دقايق، أي عند :09:00):

| الدور | العرض | المدة |
|---|---|---|
| 1 | الشعارات الكبيرة، المبنى ينزل والشعار يطلع من فوق يسار | 10 ثواني لكل شعار (50 ثانية) |
| 2 | مبنى الجامعة مع شعار الجامعة | 20 ثانية |
| 3 | الحدث القادم مع وقته | 30 ثانية |

- الاستراحات والغداء تظهر بعنوان **وقت راحة**.
- بدون حدث حالي: تظهر شاشة البداية (الشعارات المتبدلة).
- قبل أي حدث بساعة ونص (وما فيه حدث حالي): تتكرر الدورة: الحدث القادم (20 ثانية) ← الشعارات الكبيرة (20 ثانية لكل شعار) ← شاشة البداية (20 ثانية). تتغير بـ`PRE_STEP` في `js/config.js`.

## التعديل
- `js/config.js`: مدد العرض (`CYCLE`, `SLOT_AT`, `LOGO_EACH`, `CAMPUS_LEN`, `NEXT_LEN`)، الجدول `E`، والتواريخ `DATE`، ومسارات الشعارات.
- `assets/logos/`: الشعارات (هيئة البحث العلمي، الجامعة العربية، اللجنة الوطنية العمانية، الجامعة العربية المفتوحة، شعار المؤتمر). الشعار الفاتح (AOU) يُعلّم `light:true`.
- `assets/building.jpg`: صورة مبنى الجامعة.
- `css/style.css`: التصميم والحركات.

## التجربة
- `index.html#demo` يعرض كل الحركات بالتسلسل (6 مراحل) ويكررها.
- `index.html?t=2026-10-26T10:09` يحاكي وقتاً معيناً (الساعة بتوقيت مسقط). يعمل عند فتح الملف محلياً أو على Pages.

## ملاحظة
الأوقات والأسماء مأخوذة من برنامج المؤتمر (26–28 أكتوبر 2026). مدة "التوجه للحافلات" مفترضة نصف ساعة.

## الواجهة
- زر **الحدث القادم** فوق يمين: يفتح نافذة بتفاصيل الحدث القادم ووقت بدايته، وتنغلق بعد 20 ثانية أو بزر ✕ أو Esc أو الضغط خارجها.
- نص "صنع بواسطة جماعة ريادة الأعمال والابتكار" تحت في كل الشاشات.
- المؤشر يختفي بعد 3 ثواني من توقف الفأرة.
- حركة نص الأحداث بمكتبة [GSAP](https://gsap.com) (نسخة محلية في `js/vendor/gsap.min.js`، ترخيصها: https://gsap.com/standard-license). لو الملف ما تحمّل، تشتغل حركات CSS البديلة.

## الهوية البصرية (AOU Brand Book V3.0)
- **الخطوط:** Madani Arabic Regular (خط الهوية، ملف `assets/fonts/madani-arabic-400.woff2`) للعربي، وNoto Kufi Arabic احتياط، وPoppins للأرقام والحروف اللاتينية. *(النص الأصلي: Noto Kufi Arabic للعربي (الحل البديل الموصى به في دليل الهوية بدل Madani Arabic المدفوع)* الملفات محلية في `assets/fonts` (رخصة OFL مرفقة). لو عندكم ملفات Madani Arabic المرخصة، أضيفوها في نفس المجلد وغيّروا `@font-face` في أول `css/style.css`.
- **الألوان الأساسية:** الأزرق الكحلي `#002D58` والأوف وايت `#E8E6DF` (حاضران في كل الشاشات حسب الدليل)، الأخضر الداكن `#194C44`، الأحمر `#A11A16`.
- **الثانوية:** أزرق سماوي `#6DB1DE`، عنابي `#A64167`، أخضر `#007635`، بترولي `#5CBDAF`، أصفر `#F3B200`.
- كل الألوان متغيرات CSS في أول `css/style.css`.

> **تنبيه ترخيص:** Madani Arabic خط مرخّص (يشترى من MyFonts)، والملف المرفوع تعريفه يسمح بالمعاينة والطباعة فقط داخل الملفات. تأكدوا أن رخصتكم تسمح باستخدامه على الويب قبل نشر المستودع علناً.

## رموز QR
- يظهر رمزان على جانب الشاشة (افتراضياً يسار)، والضغط على أي واحد يكبّره للمسح. يقفل بالضغط عليه أو Esc أو لحاله بعد دقيقتين.
- اختصار للشرح: اضغط **1** أو **2** من الكيبورد لفتح الرمز، و**Esc** للإغلاق.
- لتغيير الصورة: استبدل `assets/qr/qr1.png` و `qr2.png` بنفس الاسم. لتغيير النص تحت الرمز: عدّل `title` و `sub` في `js/config.js`.
- في `js/config.js`: `SHOW_QR=true/false` لإظهار الرموز أو إخفائها بالكامل، و`QR_SIDE="left"` أو `"right"` لمكانها.

## ملء الشاشة
- زر الأسهم فوق يمين (جنب "الحدث القادم")، أو **نقرتين** (أو ثلاث) على أي مكان فاضي بالشاشة، أو حرف **F**. نفس الشي للخروج.

## زر "الحدث السابق"
- يفتح قائمة: **الحدث الآن** (يتغير مع الوقت الفعلي) وتحته كل الأحداث اللي خلصت (الأحدث أولاً، مقسمة حسب اليوم)، بدون أوقات. اضغط أي حدث لتشوف تفاصيله، و"الرجوع للقائمة" يرجعك. يقفل بـ ✕ أو Esc أو لحاله بعد دقيقتين.

## الوضع اليدوي (MANUAL)
- في `js/config.js`: `MANUAL=true` (الافتراضي حالياً بسبب تأخير الأوقات) = ما يمشي على الساعة وما يعرض أوقات. تتحكم أنت من أزرار تحت يسار (`CTRL_SIDE` لتغيير الجهة): **اختيار الحدث** (اختر اليوم ثم الجلسة)، و**السابق** و**التالي** للتنقل السريع.
- الحدث القادم والحدث السابق يتبعون اختيارك. اختيارك يبقى محفوظ في المتصفح لو حدّثت الصفحة.
- قبل ما تختار شي (أو "قبل البداية") تظهر شاشة الشعارات. دورة الشعارات والمبنى تستمر كل 10 دقايق.
- `MANUAL=false` يرجع للوقت الفعلي.

## التحكم عن بعد (أدمن فقط) — Firebase
الموقع على GitHub Pages ثابت وما يقدر يحفظ حالة، فنستخدم Firebase (مجاني، خطة Spark): الأدمن يغيّر الحدث من `admin.html` بحسابه، والشاشة تتحدث فوراً. أي أحد غيره ما يقدر يغيّر.

1. افتح console.firebase.google.com ← **Add project** (بدون Analytics).
2. **Build ← Realtime Database ← Create database** (اختر أقرب منطقة، وضع Locked).
3. **Build ← Authentication ← Get started ← Email/Password ← Enable**. من تبويب **Users ← Add user** أضف بريدك وكلمة مرور قوية، وانسخ **User UID**.
4. **Authentication ← Settings ← Authorized domains**: أضف `bym1c.github.io`.
5. **Realtime Database ← Rules**: الصق التالي (بدّل `UID` بالمنسوخ) واضغط Publish:
```json
{
  "rules": {
    "screen": {
      ".read": true,
      "state": { ".write": "auth != null && auth.uid === 'UID'" }
    }
  }
}
```
6. **Project settings ← Your apps ← Web (`</>`)**: سجّل تطبيق وانسخ `firebaseConfig` (مع `databaseURL`) داخل `js/firebase-config.js`.
7. في `js/config.js`: `REMOTE=true`، وارفع الملفات لـ GitHub.
8. افتح `https://bym1c.github.io/AOU/admin.html` من جوالك وادخل بحساب الأدمن: اختر اليوم ثم الحدث (أو السابق/التالي)، وتتغير الشاشة فوراً.

- الشاشة العامة تحتاج إنترنت لاستقبال التغيير، ولو انقطع تبقى على آخر حدث.
- لا تنشر كلمة مرور الأدمن، وغيّرها من Firebase لو تسربت.
